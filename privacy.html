Política de privacidad

Esta política explica qué información maneja TabVault, por qué la necesita y dónde se almacena. TabVault está diseñado como una extensión local-first y no opera un servidor propio para almacenar la biblioteca de pestañas de los usuarios.

1. Información que TabVault maneja

Cuando el usuario decide guardar pestañas, TabVault puede procesar y almacenar los siguientes datos necesarios para ofrecer su función principal:

  • URL de la pestaña.
  • Título de la página.
  • Favicon o referencia visual asociada a la pestaña, cuando esté disponible.
  • Nombre del grupo y marcas de tiempo necesarias para organizar y sincronizar la biblioteca.
  • Preferencias locales de la extensión y estado técnico de sincronización.

TabVault no inspecciona el contenido interno de las páginas, formularios, contraseñas, mensajes o pulsaciones de teclado.

2. Cómo se obtiene la información

La información de pestañas se procesa cuando el usuario utiliza funciones de TabVault para guardar una ventana, guardar o restaurar pestañas, organizar grupos o sincronizar su biblioteca. TabVault no monitoriza de forma continua el historial de navegación para fines publicitarios o de perfilado.

3. Almacenamiento local

La biblioteca y las preferencias de TabVault se almacenan localmente mediante las APIs de almacenamiento de Chrome. El usuario puede utilizar TabVault sin activar la sincronización con Google Drive.

4. Sincronización opcional con Google Drive

Si el usuario activa Google Drive Sync, TabVault utiliza la autorización de Google para acceder únicamente al espacio privado de aplicación de TabVault en Google Drive (appDataFolder). TabVault no solicita acceso general a los documentos personales del usuario.

Los datos de la biblioteca destinados a sincronización se cifran localmente antes de enviarse a Google Drive. La clave del vault no se envía a un servidor de TabVault. Si el usuario pierde esa clave, TabVault no puede recuperar el contenido cifrado.

Google puede procesar datos conforme a sus propios términos y políticas cuando el usuario utiliza Google Drive. TabVault no controla la infraestructura de Google.

5. Autenticación

TabVault utiliza las APIs de identidad de Chrome y Google OAuth exclusivamente para permitir que el usuario autorice la sincronización opcional con su propio Google Drive. TabVault no opera un sistema propio de cuentas ni recibe la contraseña de Google del usuario.

6. Venta, publicidad y transferencia de datos

TabVault no vende datos personales, no comercializa datos de navegación, no muestra publicidad y no utiliza los datos del usuario para determinar solvencia, otorgar crédito ni crear perfiles publicitarios.

Los datos sólo se transfieren cuando es necesario para la función solicitada por el usuario, por ejemplo al sincronizar la biblioteca cifrada con Google Drive.

7. Conservación y eliminación

Los datos locales permanecen en el navegador hasta que el usuario elimina grupos, borra los datos de la extensión o desinstala TabVault. Los datos sincronizados permanecen en el espacio privado de aplicación de Google Drive mientras sean necesarios para mantener la sincronización o hasta que el usuario los elimine mediante TabVault o gestione el acceso/datos desde su cuenta de Google.

8. Seguridad

TabVault aplica cifrado local a los datos destinados a Google Drive y limita sus permisos al mínimo necesario para guardar, restaurar y sincronizar pestañas. Ningún sistema puede garantizar seguridad absoluta, por lo que recomendamos conservar respaldos cuando la biblioteca sea importante.

9. Menores de edad

TabVault no está diseñado para recopilar conscientemente información personal de menores ni contiene funciones dirigidas específicamente a menores.

10. Cambios a esta política

Si cambia de forma material el tratamiento de datos de TabVault, esta política se actualizará antes o junto con la versión correspondiente de la extensión.

11. Contacto y soporte

Para preguntas sobre privacidad o soporte, utiliza el repositorio oficial de TabVault en GitHub: GitHub Issues.
