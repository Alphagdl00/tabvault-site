Política de privacidad

Esta política explica qué información maneja TabVault, por qué la necesita y dónde se almacena. TabVault está diseñado como una extensión local-first y no opera un servidor propio para almacenar la biblioteca de pestañas de los usuarios.

1. Información que TabVault maneja

Cuando el usuario decide guardar pestañas, TabVault puede procesar y almacenar los siguientes datos necesarios para ofrecer su función principal:

  • URL de la pestaña.
  • Título de la página.
  • Favicon o referencia visual asociada a la pestaña, cuando esté disponible.
  • Nombre del grupo y marcas de tiempo necesarias para organizar y sincronizar la biblioteca.
  • Preferencias locales de la extensión y estado técnico de sincronización.

TabVault no inspecciona el contenido interno de las páginas, formularios, contraseñas, mensajes o pulsaciones de teclado.

2. Cómo se obtiene la información

La información de pestañas se procesa cuando el usuario utiliza funciones de TabVault para guardar una ventana, guardar o restaurar pestañas, organizar grupos o sincronizar su biblioteca. TabVault no monitoriza de forma continua el historial de navegación para fines publicitarios o de perfilado.

3. Almacenamiento local

La biblioteca y las preferencias de TabVault se almacenan localmente mediante las APIs de almacenamiento de Chrome. El usuario puede utilizar TabVault sin activar la sincronización con Chrome.

4. Sincronización opcional con Chrome Sync

Si el usuario activa la sincronización, TabVault utiliza chrome.storage.sync, el mecanismo de sincronización de extensiones de Chrome. Chrome gestiona el transporte de esos datos entre navegadores donde el usuario tenga iniciada su cuenta y la sincronización habilitada.

Antes de escribir URLs y títulos en Chrome Sync, TabVault comprime y cifra los datos localmente con AES-GCM usando una clave derivada de la contraseña del vault. La contraseña del vault no se sincroniza. Si el usuario decide recordarla, se conserva únicamente en el almacenamiento local de la extensión en ese equipo.

TabVault no opera un servidor propio ni recibe credenciales de la cuenta de Google o Chrome del usuario.

Chrome Sync tiene límites de almacenamiento. Si se alcanza la cuota, TabVault conserva la biblioteca local y el usuario puede seguir utilizando respaldos JSON.

5. Cuenta y autenticación

TabVault no crea cuentas propias y no utiliza Google OAuth. La sincronización depende de la configuración de Chrome Sync del navegador. TabVault no recibe ni procesa la contraseña de la cuenta de Chrome o Google del usuario.

6. Venta, publicidad y transferencia de datos

TabVault no vende datos personales, no comercializa datos de navegación, no muestra publicidad y no utiliza los datos del usuario para determinar solvencia, otorgar crédito ni crear perfiles publicitarios.

Los datos sólo se sincronizan cuando el usuario activa esa función y únicamente mediante Chrome Sync, en forma cifrada por TabVault.

7. Conservación y eliminación

Los datos locales permanecen en el navegador hasta que el usuario elimina grupos, borra los datos de la extensión o desinstala TabVault. Los datos sincronizados permanecen en Chrome Sync mientras formen parte del vault sincronizado. El usuario puede eliminar grupos desde TabVault; la biblioteca local también puede eliminarse al borrar los datos de la extensión o desinstalarla.

8. Seguridad

TabVault aplica cifrado local a los datos destinados a Chrome Sync y limita sus permisos al mínimo necesario para guardar, restaurar y sincronizar pestañas. Ningún sistema puede garantizar seguridad absoluta, por lo que recomendamos conservar respaldos cuando la biblioteca sea importante.

9. Menores de edad

TabVault no está diseñado para recopilar conscientemente información personal de menores ni contiene funciones dirigidas específicamente a menores.

10. Cambios a esta política

Si cambia de forma material el tratamiento de datos de TabVault, esta política se actualizará antes o junto con la versión correspondiente de la extensión.

11. Contacto y soporte

Para preguntas sobre privacidad o soporte, utiliza el repositorio oficial de TabVault en GitHub: GitHub Issues.
