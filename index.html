Privacidad · Soporte
Chrome Extension · Local-first

Tus pestañas, organizadas y bajo tu control.

TabVault convierte ventanas llenas de pestañas en una biblioteca que puedes restaurar cuando la necesites. La sincronización con Chrome Sync es opcional y los datos se cifran localmente antes de sincronizarse.

Guarda por grupos

Convierte una ventana completa en un grupo organizado y restaura pestañas cuando quieras.

Funciona offline

La biblioteca vive primero en tu navegador. No necesitas conexión para guardar y consultar tus grupos.

Sync opcional

Usa Chrome Sync para sincronizar entre equipos sin una cuenta TabVault ni un servidor propio.

Cifrado local

Los datos destinados a Chrome Sync se comprimen y cifran antes de sincronizarse.

Privacidad por diseño

TabVault no vende datos, no muestra anuncios y no utiliza tu actividad para crear perfiles publicitarios. Puedes usar la extensión únicamente de forma local o activar Chrome Sync cifrado cuando necesites compartir tu biblioteca entre equipos.
